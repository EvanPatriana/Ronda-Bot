# 📱 Sistem Laporan Ronda Otomatis - Telegram Bot

Sistem laporan ronda realtime berbasis Bash Script + Telegram API, dibuat di Android menggunakan Termux.

### 🚀 Fitur
- Laporan 1 baris: `./ronda_telegram.sh "Pos aman"`
- Otomatis catat jam & tanggal: `[10:55 26/10] Pos 2 aman, lampu mati 1`
- Simpan lokal di `buku_ronda.txt` sebagai backup
- Kirim otomatis ke Telegram pribadi
- Alarm harian jam 7 pagi

### 🛠️ Teknologi
- Bash Script
- Telegram Bot API
- cURL & JSON
- Linux (Termux Android)
- Automation & Logging

Tested: Laporan berhasil terkirim ke Telegram pada 26/10 pukul 10:55 WIB
